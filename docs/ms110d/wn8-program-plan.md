# WN8 redesign program — program plan

Registered 2026-07-31, before any DSP work, per the Phase B rule ("exactly as phase-b-plan.md registered before any of it ran" — [phase-b-closeout.md](phase-b-closeout.md)). This is a standalone successor program, deliberately **not** named "Phase C": design §6's ladder owns Phase C for WN9–12, and `c0` already names an OTA evidence dir. Leg IDs are `W0…W6`; evidence dirs `evidence/YYYY-MM-DD-wn8-<leg>/`; branches `wn8-<leg>`.

## 1. Charter

Attack the one remaining MS110D Poor point: **WN8 (16QAM r3/4, U=256/K=32) at +23 dB against the 1E-5 coded-BER mask**, closed by Phase B measured-only at coin-flip (4.96E-1 canonical / 4.97E-1 disjoint) behind two measured walls ([phase-b-closeout.md](phase-b-closeout.md) §4, re-measured on the current chain in [evidence/2026-07-26-phase-b39-wn8-verdict/](evidence/2026-07-26-phase-b39-wn8-verdict/)):

- **Wall 1 — model ceiling**: the true-label ceiling is 9.2E-4 canonical (92× mask, 10/11 blocks nonzero) / 2.5E-4 disjoint (25×). The probe-trained T/2 DFE + tail-tracking + chain-BCJR model class cannot track 16QAM at 23 dB Poor even with perfect decision labels (B3.10).
- **Wall 2 — bootstrap basin**: the first decode is coin-flip (~49.8%) and every label-free iteration attempt asymptotes back to ~50.1% — a self-consistent wrong attractor (B3.4).

Every candidate must name **which wall it attacks**; a gate needs **both** walls down. **Scope is receiver-only**: the wire waveform is fixed by MIL-STD-188-110D App D and stays byte-exact to spec. Pilots-in-data, altered probe cadence, or any TX-side change is out of scope — such a waveform is no longer App D WN8 and cannot claim the D-LXIV mask row. Non-goals: WN7 (its B3.9 verdict stands — needs added information, a protocol-layer question), WN9–12, on-air gating (§5).

**Three acceptable exits** — the deliverable is a measured, written verdict, not necessarily a gate flip:

- **(i) Hard-gated at mask**: both walls measured down; W6 battery green under the full gate story; WN8 joins the default-armed Poor set.
- **(ii) Improved but measured-only**: a new honest ceiling (e.g. coin-flip → 1E-3) merged through the full guard story; `MS110D_POOR_GATED=1` expected-red values re-banked; closeout states the new ceiling and what remains.
- **(iii) Measured infeasible**: the waveform's own floor at this channel/SNR under any implementable receiver-only class — closed exactly like WN7's B3.9 verdict ("needs added information"), banked negatives extended, no demod change shipped. A strengthened verdict is a program success.

## 2. Starting position — what is already measured

- The b34 "genie" run (WN8 genie 268,541 vs normal 269,237 coded errors — indistinguishable, [evidence/2026-07-25-phase-b34-wn8/](evidence/2026-07-25-phase-b34-wn8/)) is a **perfect-channel-observation** bound, not perfect channel knowledge: `MS110D_MASK_GENIE=1` feeds the estimator a noise-free copy of the same faded waveform, but the estimator still sees the channel only through probes + decision-directed updates — which at a coin-flip start pass ~nothing. **No instrument has ever injected the true per-symbol tap trajectory into the detector.** That decisive measurement is leg W1, and it is cheap: `Ms110dChainBcjr.Equalize` already takes per-position `h1`/`h2`/`noiseVarPerSymbol`/`symbolLogPriors` spans, and the Watterson rig records true gain trajectories at 96 Hz (`WattersonChannel.GainSampleRateHz`).
- **Physics budget**: Es/N0 ≈ 24 dB at the +23 dB (3 kHz) operating point. The Table D-VII constellation is 12 outer points on the unit circle at 30° + 4 inner at r ≈ 0.366; min distance 0.366 → (d/2)/σ ≈ 4.1 at nominal gain — near-zero coherent margin; the r3/4 code + 7.68 s Long interleaver must absorb all fading. Channel-estimation budget: ~−30 dB NMSE in the healthy bulk for ≤1 dB detection loss, **plus exact heteroscedastic pricing** so faded spans become honest erasures (the WN7 B3.9 lesson: the code tolerates erasures, not mispricing).
- **Probe-only interpolation is not information-starved in principle**: the probe-anchor series samples the ≲±1.5 Hz Watterson process at 8.33 Hz (3–4× Nyquist), and per-anchor LS from K=32 known symbols sits ~−39 dB per tap. But B3.8's decomposition measured frozen-h1 model error already sub-dominant at WN7's floor (~2% median / 13% p90), so the 92× ceiling is carried by some other term — within-segment motion near nulls, per-segment h₂ granularity, beyond-{0,d,d±1} response, or pricing. **Nobody has decomposed it; that is W2.**
- **A label-free bootstrap observable exists that Phase B never tried**: the outer ring is a 12PSK, so x¹² = 1 exactly for all 12 outer points (inner r¹² ≈ 6E-6, negligible; the scrambler is an index permutation of the same point set, so symbol moments are scramble-invariant). Windowed y¹² ≈ 0.75·Σₖgₖ¹²(t) is a mid-frame phase track without labels (30°-ambiguous, continuity-resolved from probe anchors); windowed |y|² ≈ Σₖ|gₖ|²(t) + σ² tracks the envelope. This is precisely the information the B3.4 verdict said "only labels provide" — without labels, on aperiodic data (immune to the base-16 probe aliasing). Its real accuracy over fades is measured offline in W3 before anything ships.
- **Feasibility is genuinely uncertain**: WN7's floor with everything working was already above its mask at an easier operating point (8PSK, +19 dB). It is a live possibility that the true-channel floor of this waveform at +23 dB exceeds 1E-5 — which is why W1 (the feasibility bound with a pre-committed kill rule) runs before any architecture is built.

## 3. Discipline (binding, carried from Phase B)

- **Registration before running.** Every leg registers, in its evidence-dir README before any code or run: the question (one, decidable); decision inputs (already-banked measurements only); the mechanism claim; the instrument + method (exact seeds, env knobs, validity cross-checks — the ship side must reproduce the W0 census rows exactly); the budget; a **pre-committed numeric kill/proceed rule** (the B3.10 "≥10× on either specimen → design-only close" precedent).
- **Order rules**: cheapest decisive measurement first; **ceiling instruments before implementations** (bound every lever with an oracle before building it); corpse before battery; battery only at leg exit or pre-merge.
- **Specimens**: canonical w0/b0 channelSeed **509**, disjoint w0/b0 channelSeed **10509** (composition `channelSeed = SEED + worker·10⁶ + burst·10³ + 1`, SEED 508/10508). Never share an OUT dir between same-(wn,worker,burst) runs from different SEEDs.
- **Escalation rule** (phase-b-plan §4, verbatim): any candidate still above its registered target when its stage budget closes gets a written stop-and-reassess — options on the table, cost of each — not more tuning.
- **Banked negatives** ([phase-b-closeout.md](phase-b-closeout.md) §5) are do-not-retry; every registration cites its clearances. Chief among them here: the oracle-labels pass is a **reference, not a bound**; per-bin FD MMSE is dominated by the exact chain BCJR **at equal channel knowledge** (an FD candidate must bring new channel knowledge or it re-treads B3.7); no label-free bootstrap crossing exists **in the current loop structure**; restart ensembles and start-side LLR calibration are dead.
- **Guard pins** ([phase-b-closeout.md](phase-b-closeout.md) §6) re-prove on any demod change: WN7 corpse w0/b0 (0 coded / 11c/0r/4v / oracle b5:15), WN7 w1/b0 (20 coded / 11c/0r/5v), WN6 w0/b0, WN13sp, WN0 w2/b97, hermetic suite at its W0-re-pinned count, non-target battery censuses byte-identical to the W0 baseline, both seed families, Phase A regressions green. Merge order: registration → corpse → full three-lane battery → merge.
- **New instruments get their own calibration lane** before they are trusted (the B0 rule; Phase B caught four instrument defects that way). Any tuned constant faces the off-rig direction checks ({1 ms, 0.5 Hz}, {3 ms, 2 Hz}, static) — no constant may encode the rig.
- **Shipped-path changes are structurally scoped to QAM16** ("only structural scoping retains exactly" — B3.8); new knobs ship report-only.
- **Battery hygiene**: three-lane detached (`setsid`), fleets expendable, never rebuild mid-battery; corpse runs (minutes) are the daily iteration unit, batteries (~33 min) at most 1–2/day at leg exits or pre-merge.

## 4. Leg ladder

- **W0 — entry re-baseline (S).** Main has moved past the b38 byte-identity baseline (PR #103's AGC, the OTA-era work). Run the hermetic suite (re-pin its count) and a full three-lane battery on current main; verify the gated-eight censuses at their exact digits, the WN7/WN8 measured rows, and the §6 guard pins. This battery becomes the program's byte-identity baseline. Kill/proceed: any drift → stop and diagnose before any DSP work.
- **W1 — true-channel injection bound (M) — the program gate.** Env-gated truth seam: exact per-symbol h₁(t)/h₂(t) (96 Hz truth → symbol rate, gauge-mapped through the FF into the chains' model class, reusing the B3.3 fade-crossing gauge) + exact per-symbol pricing, measured first-pass-only and with the banked b34 QAM16 turbo wiring re-armed, on both family specimens. Reads: (a) truth-in-model-class BER vs the 9.2E-4 oracle ceiling — sizes the knowledge gap; (b) first-decode-with-truth — does perfect knowledge alone cross the basin? Kill/proceed: ≤~2× mask-class on both specimens → Wall 1 is knowledge-only, candidate (a) becomes primary; ≥10× → run **W1b** (corpse-only full time-varying-MAP on the effective channel, test-side, no hot-path constraints); W1b also ≥10× → **registered infeasibility verdict for any receiver-only program — exit (iii), program closes honestly.**
- **W2 — oracle-residual anatomy (M).** Which model-budget term carries the 92×/25× ceiling: within-segment motion, per-segment h₂ granularity, beyond-{0,d,d±1} response (the B3.7 FD revival condition, re-measured at 16QAM's tighter geometry), or pricing. B3.9-style per-error anatomy + offline decomposition scripts on oracle corpse logs; near-zero build cost. Output: a ranked deficiency budget selecting candidate (a) vs a chain-representation upgrade vs (c); candidate (b) stays dormant unless its revival condition fires here.
- **W3 — bootstrap physics, offline (M).** Windowed |y|² and y¹² accuracy vs recorded truth (autopsy wire-sample dump + offline analysis; no demod change): per-symbol phase/amplitude NMSE as a function of window length and fade depth; ambiguity-slip rate through fades; fraction of frames meeting the W1-measured NMSE requirement when moment tracks combine with probe anchors. Kill: coverage insufficient at generous windows → the moment/partial-bit bootstrap dies; with W1 green that leaves only (c)-class joint estimation for Wall 2, and if that is implausible the honest endpoint is the §1 boundary statement.
- **W4 — candidate ceiling pricing (S/M).** Fit each surviving candidate's model class to the truth samples, inject via the W1 seam → that candidate's own ceiling on the corpses. Registered bar: build only candidates priced ≤~2× mask. (Per the banked negative, a good ceiling is necessary, never sufficient — it kills, it does not guarantee.)
- **W5 — build the estimator (L).** Expected shape if (a) survives: a per-block Kalman/BEM smoother over each data span — probes as boundary conditions + moment track + iteration-≥1 soft decisions — feeding the existing chain BCJR; label-free iteration-0 = probe + moment track only (the ingredient B3.4's bootstrap lacked). Changes confined to the block re-equalization span construction; zero steady-state allocation; structurally scoped to QAM16. Corpse-first with full discipline; basin crossing must reach an **exact fixed point** (a self-consistent iterate without a fixed point is not evidence — the 50.1% attractor is the cautionary specimen).
- **W6 — battery, gate decision, closeout (S/M).** Full §5.3 accept rule (≥3×10⁶ payload bits, ≥600 s, zero acquisition failures, ≥30 errors → direct BER ≤1E-5 else 97.5% Poisson bound clears), both families; 3M-vs-6M default budget by the B4 false-red criterion (≤5% per-family false-red); guard pins; byte-identity; one of the three §1 exits; program closeout doc + [mode-validation.md](../mode-validation.md) ledger + plan.md amendment.
