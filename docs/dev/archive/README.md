# Archive

These are records of work as it happened: closed plans, campaign evidence, handovers, closeouts and the closed amendment log of the plan.

They are never edited. A record says what was written at the time, and correcting it later would falsify it, so a statement in one of these files that is now wrong stays as it is.

They may describe code that has since changed or left this repository.

Links inside them may point at paths that have moved. Read a path in an archived file as the path at the time of writing.

The current state is in [docs/dev](../README.md) and in the guide under docs/.
