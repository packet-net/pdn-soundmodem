# Roadmap

Status: current as of 2026-10-10. Describes where open work is tracked.

Open work is tracked as [GitHub issues](https://github.com/packet-net/pdn-soundmodem/issues), not in this repository. A larger programme of work is an issue labelled `epic` with its pieces as sub-issues; `needs-radio` marks work that needs Tom, a radio and bench or air time; `parked` marks a recorded request or decision that is not scheduled; and a question that has been settled against building something is an issue closed as not planned with the `ruled-out` label, so a search finds the reason.

Before 2026-10-10 this file was the roadmap. It is frozen at [archive/roadmap-2026-10.md](archive/roadmap-2026-10.md), which also says which issue each of its numbered items became. Its item numbers #4 to #19 were its own, not GitHub numbers.

The rules the roadmap carried for all work (the standing directives) are in [README.md](README.md#standing-directives).
