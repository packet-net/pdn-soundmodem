# pdn-soundmodem — mode validation report and provenance ledger

Living document. Tracks every mode string accepted by `ModemCatalog` (`src/Packet.SoundModem/Modems/ModemCatalog.cs`), how each has been validated (simulation and over-the-air), and — the point of this file — a dated, append-only ledger of *who/what proved a mode working*, with special attention to modes that were **broken and later fixed**, so a regression can always be traced back to the evidence that closed it the first time.

## Purpose and maintenance rule

This file exists because "does mode X work" is otherwise answered by grepping commit messages and hoping. Two things must stay true as the project moves:

1. **Every mode string in `ModemCatalog.KnownModes` appears in the matrix below**, with its current status. When a mode is added, removed, or renamed in the catalog, this file changes in the same PR (mirrors the `docs/plan.md` discipline).
2. **Every time a mode's validation status changes — especially broken → fixed, or working → regressed — append a dated entry to the [Validation ledger](#validation-ledger)** citing the exact commit hash, PR number, and/or issue number that did it, plus the evidence (mask figures, corpus decode counts, on-air BER). Do not edit or delete a prior ledger entry to "correct" it in place; append a new one and let the old one stand as the historical record. Where the provenance is genuinely not known, write **TBD** — never invent a commit, PR, or issue number.

Status legend used in the matrix:

- **working** — validated both in simulation/interop and confirmed over real RF (or, for corpus-based checks, against a real captured off-air/rig recording).
- **partial** — validated in simulation, but the on-air/interop result is mixed, marginal, or has a known open issue against it.
- **untested** — no meaningful validation recorded beyond the mode constructing (`ModemCatalog.Create` succeeding), or coverage is too thin to call it exercised.
- **not-yet-on-air** — solid simulation/interop validation; no real-RF attempt has been made yet.
