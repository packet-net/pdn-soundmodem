# STANAG 5066

pdn-soundmodem can run a STANAG 5066 node on your station. Applications talk to it over the standard Subnetwork Interface (SIS) on TCP port 5066, and it sends over the MIL-STD-188-110D waveform through your sound card and PTT. The node is [M0LTE.S5066](https://github.com/M0LTE/M0LTE.S5066); pdn-soundmodem gives it the radio.

It is off unless you ask for it. A station without an `s5066` section runs exactly as before.

## Turn it on

Add an `s5066` section to your config file and restart the service:

```json
{
  "device": "plughw:CARD=Device,DEV=0",
  "ptt": { "type": "cm108", "device": "/dev/hidraw0" },
  "s5066": {
    "port": 5066,
    "node": {
      "local_address": "0.0.1.1",
      "csma": { "mode": "jitter" },
      "drc": { "default_speed": { "wn": 6, "interleaver": "short" } },
      "cas": { "max_links": 4, "link_request_retries": 5, "break_retries": 3 }
    }
  }
}
```

- `local_address` is this node's STANAG 5066 address. Give every node on the net its own.
- `csma.mode` and the three `cas` counts have no default in the standard, so you have to choose them. The other settings take M0LTE.S5066's defaults; its `docs/core-architecture.md` lists them.
- Your packet modems keep working beside it, and the channel runs at 48 kHz. ARDOP cannot share a station with it.
- Until [issue #785](https://github.com/packet-net/pdn-soundmodem/issues/785) is fixed, run the node on a channel without packet modems.

The journal should show:

```
s5066 sis tcp: 127.0.0.1:5066 (node 0.0.1.1, MIL-STD-188-110D on the 48000 Hz channel, busy input from the channel's carrier sense)
```

Set your transmit level with a test tone first ([04-levels.md](04-levels.md)). The 110D waveform fills a 3 kHz SSB passband, so open the radio's filter to at least that.

## Point a client at it

Any SIS client can connect. To try it, the chat sample in M0LTE.S5066 does:

```sh
git clone https://github.com/M0LTE/M0LTE.S5066
cd M0LTE.S5066
dotnet run --project samples/HfChat -- --node 127.0.0.1:5066
```

Type `/to 0.0.1.2` to talk to another node, then type a line. Do the same at the other station with its own address. `/all` sends to everyone.

## Good to know

- The SIS port listens on the `bind` address, loopback by default. The SIS has no password, so think before opening it to your network.
- The standard's channel access is slow on purpose: with its defaults one confirmed message can take a minute or more. The waits are under `csma` if your net agrees shorter ones.
- The node defers to the channel's carrier sense: your radio's, if you have a `carrierSense` section, otherwise what the packet modems hear.
- If a `csma` slot is too short for the modem's preamble, the service logs a warning at start-up rather than refusing the file.
- Every setting is in [reference/config.md](reference/config.md#s5066).
